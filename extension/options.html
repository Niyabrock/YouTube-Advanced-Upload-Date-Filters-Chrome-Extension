Enable YouTube Data API v3 in your Google Cloud project and create an API key restricted to that API. The key stays in this browser’s local extension storage and is sent only to Google’s API.

Browser extensions cannot keep a client API key secret from the device owner. Use a separate project, set quota alerts, and never use a privileged server credential. Website referrer restrictions may reject extension requests.

Each search or next page costs 100 quota units. Default daily quotas often allow about 100 requests. No key is bundled.
